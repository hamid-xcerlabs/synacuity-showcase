# Disclosure

This repository is a public technical showcase of Synacuity, a production AI intelligence platform for multi-location restaurant operations.

The production application and source code are maintained privately due to client intellectual property, security, and customer-data requirements.

## What this repository includes

This public repository is intended to demonstrate the engineering behind the system without exposing proprietary implementation details.

It may include:

- System architecture
- Product workflows
- Engineering decisions
- Multi-tenant design concepts
- Event-ingestion patterns
- AI-processing architecture
- Reliability and retry strategies
- Data-model concepts
- CI/CD approach
- Observability and AI cost-tracking concepts
- Sanitized product screenshots
- Synthetic examples

## What is intentionally excluded

This repository does not include:

- Production source code
- Proprietary prompts
- Client-specific business logic
- Customer review data
- Customer identities
- Internal account identifiers
- Store or location identifiers
- API credentials or secrets
- Production environment variables
- Private deployment configuration
- Authentication credentials
- Internal operational data
- Client-confidential documentation

## Data shown in screenshots

Any screenshots included in this repository are sanitized for public display.

Personally identifiable information, customer names, review content, private account details, and internal identifiers are removed, blurred, or replaced where necessary.

Any example review content shown publicly should be treated as synthetic unless explicitly stated otherwise.

Public documentation in this repository describes high-level architecture and engineering decisions only. It should not be interpreted as a release of the production codebase or any client-owned intellectual property.
